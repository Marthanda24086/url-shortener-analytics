ENTROPY SPACE

56.8 Billion Hashes

Generated via Node.js CSPRNG crypto.randomFillSync utilizing a 62-character alphabet ([0-9, a-z, A-Z]). Six characters produce 62⁶ deterministic permutations with automatic collision escalation.

ZERO NETWORK OVERHEAD

Offline MaxMind GeoIP

Resolved in-memory in less than 0.1ms using embedded binary database lookup. Extracts country, city, and ISO regions without making external network calls.

HARDWARE SPECS

Device Fingerprinting

Deep User-Agent inspection categorizes requests into mobile, tablet, or desktop, alongside operating system kernel, browser vendor, and automated crawler bots.

GDPR CONFORMS

Salted IP Anonymization

No raw IP addresses are ever written to disk. IP inputs are concatenated with a rotating secret salt and hashed through SHA-256 to allow unique visitor calculation without retaining PII.
